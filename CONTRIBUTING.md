# Contributing

Issues and small, focused contributions are welcome, except for security problems: report those privately, as [SECURITY.md](SECURITY.md) describes. This is a personally maintained project; response and release timing are not guaranteed. Read [AGENTS.md](AGENTS.md) before asking a coding assistant to build or change it.

## Every source change includes a README review

Review the README's benefits, installation, requirements, controls, limitations, links and demo media against the resulting behavior. Update affected documentation in the same change. Internal changes need no cosmetic edit: explain **README reviewed: no change — <specific reason>** in the verification record or pull request description.

For a pull request, describe:

- What changes for the person using ClipEdge.
- How you verified the change.
- Which README claims or media changed, or why none needed an update.

Check relative links and assets in the rendered README. If visible behavior changes, refresh affected [demo media](docs/demo/README.md) with invented data only. Keep public docs in the source export so the next release preserves them.
