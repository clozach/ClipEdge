# ClipEdge app icon

`AppIcon.icns` is the blue clipboard artwork recovered from the supplied original ClipEdge 1.3.1 (build 10). SHA-256: `0f584d65a787475a8f28f259eabf0349a4cf35bf95dea11e7f86462cdeea062f`.

Chris Lozac'h confirmed authorship/publication rights on 2026-10-02 and licenses this artwork along with the code under the repository’s MIT License. The build copies this icon into the bundle before signing; the app header reads that same artwork.

The development vault also retains `InstalledGetInfoIcon.zip`, an undo copy of a manually pasted Finder resource fork. It is deliberately excluded from standalone source exports and binary releases; it is not a build input.
